# くり上がり・くり下がりの点（筆算の点アニメーション）

2けた以上のたし算・ひき算を、点・10の棒・大きな点（百・千・万）の動きで1手ずつ見せる試作。
暗算(たし算)・暗算(ひき算)TA の結果画面で、まちがえた型（くり上がり・くり下がり）の問題を再生する想定。

## 版

| ファイル | 対消滅の見せ方 | 状態 |
|---|---|---|
| `annihilate-one-by-one.html` | ひく点が1こずつ、真上のひかれる点へ下から動いてぶつかり、光の輪と火花ではじけて消える。十の位は1こずつの早送り。音は1回ごとに半音ずつ上がる | 利用者の評価「とても良かった」。採用はせず、記録として残す |

単体の HTML。ブラウザで開くと動く（外部はフォントだけ）。

## 決まっていること（どの版も共通）

- 点1つが1。縦に10つながった棒が10。百からは一辺3倍の大きな点1つに「百」「千」「万」と書く
- 位は右から 一・十・百・千・万。位がふえたら左へスクロール。手が進むと、その位が見えるところまで自動で動く
- 色：水色＝1つめの数、みどり＝2つめの数、黄色＝くり上がり・くり下がりで動く10、赤＝ひけるかどうかの判断（点滅する枠）
- くり上がり：10そろうと黄色 → 合体して上の位へ（「ガシーン」の音・ふくらんで戻る・火花）→ 次の手で残りをそろえる
- くり下がり：ひけるかどうかを赤枠で判断 → 上の位から1つかりる（黄色）→ 10にくずす。0が続く位はまたいで順にかりる
- ひく数は、ぶつかる相手（くずした10）の真下に置く。ひかれる数は、ひく数に近い下の方から使う
- 塊の右下にその塊が表す数。いちばん上の位の数字を大きく、0は同じ大きさで薄く。くり下がりでできた塊は上から2けためまで目立たせる
- 最下段（答えの段）へは、点は1こずつ、棒は1本ずつ順に流し込み、着地で減速する
- 音は「おと」をオンにしたときだけ（教室で40台が同時に鳴らないよう、初めはオフ）
