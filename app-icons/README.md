# アプリのアイコン（タブ・ブックマーク）

GAS のウェブアプリに、外部の置き場（GitHub・jsDelivr など）を使わずにアイコンを付ける方法と、アイコンの絵の作り方。
最初の例は homeroom-tools の SSS（児童理解支援システム）。

| ファイル | 内容 |
|---|---|
| [make_icon.py](make_icon.py) | アイコンの PNG を作る（文字を重ねて縁取る形）。base64 と見本の画像も出せる |
| [gas-favicon.gs](gas-favicon.gs) | GAS 側の部品（ドライブに画像を置く・`setFaviconUrl` に渡す） |
| [sss.png](sss.png) | SSS で採用したアイコン（64×64） |

## 仕組み
- GAS のウェブアプリのアイコンは `HtmlOutput.setFaviconUrl(url)` で指定する。**画像の URL しか渡せず**、GAS 自身は画像を返せない。
- 画像は **コードの中に base64 で持ち**、`ensureIcon_()` が所有者のドライブに PNG を作り、そのファイルの URL を渡す。外部の置き場は要らない。
- 共有：学校のドメインの中で、リンクを知っている人が見られる設定（`DOMAIN_WITH_LINK`）。ドメインでその共有が禁止されていれば、リンクを知っている全員（`ANYONE_WITH_LINK`）にする。画像に個人情報は入れない。
- 画像の版を `ICON_VER`（base64 の長さと末尾）に覚えるので、**画像を替えた版を貼って selfTest を実行すれば自動で作り直す**（前の画像はドライブのゴミ箱へ）。`ICON_ID` を手で消さなくてよい。

## 手順（新しいアプリに付ける）
1. 絵を作る：`python3 make_icon.py ABC -o abc.png --preview prev.png`。見本で 16px の見え方を確かめ、値を詰める（下の「絵の決め方」）。
2. base64 を出す：`python3 make_icon.py ABC -o abc.png --b64`。出力を `gas-favicon.gs` の `ICON_PNG_B64` に貼り、`ICON_NAME` を替えて、アプリの server.gs に写す。
3. `setup` と `selfTest` から `ensureIcon_()` を呼ぶ（selfTest は ○✕ を出す）。`doGet` で `setFaviconUrl(iconUrl_())` を try で包んで渡す。
4. `appsscript.json` の `oauthScopes` に `https://www.googleapis.com/auth/drive` を入れる（`DriveApp.createFile` に要る）。
5. テストの模擬（gas-mock）に `DriveApp.createFile`・`setSharing`・`setTrashed`・`Access`・`Permission`、`Utilities.base64Decode`・`newBlob`、出力の `setFaviconUrl` を足す（homeroom-tools の tests/gas-mock.mjs が例）。
6. 反映：コードを貼る → エディタで selfTest → 承認 → 「新しいバージョン」でデプロイ。

## 絵の決め方
- **16px で決める**。タブとブックマークバーの実寸は 16px。64px で良く見えても、16px で潰れれば意味がない。見本は 16・32・64px と暗い背景で並べて見る。
- **正方形を埋める**。横に並べただけの文字列は横長になり、枠に収めると上下が空いて小さく見える（SSS の初版がそうだった）。縦に伸ばす（`--stretch`）か、重なりを深くして（`--overlap`）正方形に近づける。
- **1文字ずつ縁取って重ねる**。3つまとめた外側だけを縁取ると、重なった部分の境目が消えて字が読めない。1文字ずつ縁取り、奥から順に置くと、手前の字が奥の字を隠して文字数が読める。
- **太い字の形が単純なフォント**（Inter Display ExtraBold／Black）。線の細いフォントや斜体は小さくすると潰れる。
- **重ねすぎない**。SSS では、伸ばし 1.9 倍・重なり 5.5割にすると、奥の字が細い筋になって3つ重ねと読めなくなった。1.6 倍でも、タブの実物では少し縦長に見えた。採用は 1.45 倍・5割。
- **色は落ち着かせる**。児童の端末の画面にも出るので、目を引かない灰色（#606870）の縁と白の字にした。暗い背景でも縁で形が保たれる。
- **どちらを手前にするか**（`--front`）。左を手前にすると、読み始めの字（先頭の S）が欠けずに見える。SSS は左を手前にした。
- **大きく描いてから縮める**（作業用 512px → 64px）。縁がなめらかになる。

SSS で比べた案（どれも 16px での見え方で判断した）：

| 案 | 内容 | 結果 |
|---|---|---|
| 灰色の角丸の四角に白の S | 1文字 | 採らず（SSS を表したいという利用者の希望） |
| 外側だけを縁取った SSS | 横並び・重なり半分 | 境目が消えて読めない |
| 1文字ずつ縁取った SSS（横並び） | 重なり4割 | 採用したが、横長でタブでは小さかった |
| 同・縦に 1.6 倍、重なり5割 | 正方形に近い | 一度採用したが、タブの実物では少し縦長 |
| 同・縦に 1.45 倍、重なり5割 | ほぼ正方形 | 右の字が手前の形で一度採用 |
| 同・左の字を手前に（`--front left`） | 先頭の S がはっきり見える | **採用** |
| 同・縦に 1.9 倍、重なり5.5割 | 縦長 | 奥の S が筋になる |

## 注意点
- **承認の画面でドライブのチェックを外さない**。今の Google の承認画面は権限を1つずつ選べる。ドライブを外すと selfTest のアイコンと控えだけが「✕」（`DriveApp.createFile を呼び出す権限がありません`）になる。承認画面が出なくなったら、https://myaccount.google.com/permissions でスクリプトの権限を取り消してから実行し直す。
- **エディタの appsscript.json は隠れている**。「プロジェクトの設定 → 『appsscript.json』マニフェスト ファイルをエディタで表示する」で出してから貼る。貼り忘れるとドライブの権限が無いままになる。
- **ドライブの画像の URL を favicon に使えるという公式の説明は無い**。`uc?export=view&id=…&.png` の形で、学校の Chrome のタブとブックマークバーに出ることを SSS で確かめた（2026年11月）。出ない環境があれば、URL の形を変えて試す。
- **ブラウザはアイコンを覚えている**。差し替えても変わらなければ、ブックマークを付け直す。
- 画像の大きさは 64×64 で 7KB ほど（base64 で 9KB）。コードの文字数の制限には遠い。
- `setFaviconUrl` が失敗しても画面は開くように、try で包む。アイコンは無くてもアプリは使える。
