# UI の型（ui-patterns）

小学校向けサイトの画面で、部品の見せ方を決めるときの見本。

- **規則の正本はここではない**: 部品の選び方（どの状態にどの部品を使うか）の正本は、リポジトリ `-` の `skills/ui-layout/SKILL.md`「切り替えの部品の選び方」。理由は `principles/site-design-philosophy.md` 原則1「選択肢の見せ方で判断の回数を減らす」と `principles/low-cost-evaluation-axes.md`。ここには見た目の見本だけを置き、規則を書き写さない（食い違いを防ぐ）。

| 見本 | 内容 |
|---|---|
| [choices.html](choices.html) | 選択肢の見せ方：入／切はスイッチ1つ＋状態の文字、まれに変える多択は今の値だけ（押すと選択肢）、説明は「？」、まれな設定は「くわしく ▼」、複数のしぼり込みは要約1行＋開くパネル、目的違いの同種ボタンは1つ＋メニュー。題材は といボード（sougou）の先生画面 |
