# 色2（サイトの色）の台帳

成長する図形の**色2はサイトごとに変える**。どのサイトの床かが色で分かるようにするため。
色1は学年の色（各サイトの学年で決まる）。

## 使える色（宝石の名の8色）

算数タイムアタックでは `common/Core.gs` の `FLOOR_GEMS_` が同じ一覧を持つ。変えるときは両方を直す。

| 名前 | 色 | 呼び名 |
|---|---|---|
| amethyst | `#8A6CE5` | すみれ |
| sapphire | `#3D6FD6` | 青 |
| topaz | `#E0A43A` | こはく |
| peridot | `#8DC63F` | 若葉 |
| aquamarine | `#49B9DF` | 空 |
| rose | `#E27DB0` | 桃 |
| garnet | `#B5476B` | えんじ |
| citrine | `#D4C04A` | からし |

- 学年の色と同じ色は使えない（2つの層が見分けられない。`validateUnit_` が落とす）
- 同じ学年のサイトどうしは、なるべく別の色にする（児童が複数のサイトを行き来するため）

学年の色（参考）：1年 `#F1B1E4` / 2年 `#49B9DF` / 3年 `#35D0A5` / 4年 `#8A6CE5` / 5年 `#D4D454` / 6年 `#E4B195`

## 割り当て

| リポジトリ | サイト（単元） | 学年 | 図形 | 色2 | 状態 |
|---|---|---|---|---|---|
| arithmetic-timeattack | 九九（kuku） | 3 | penrose | amethyst | 床あり |
| arithmetic-timeattack | あまりのあるわり算（divmod） | 3 | octagon | sapphire | 床あり |

新しく床を出すサイトは、この表に1行足してから実装する。同じ学年のサイトは、図形か色2のどちらか（できれば両方）を変える。
