# 新しい図形を足す手順

「同じ育ち方（無地 → 輪郭 → 色1 → 色2）で、別の図形」を足すときの手順。
図形ごとに書くのは `generators.js` の生成器1つだけで、育ち方・色・描画は触らない。

## 0. まず多重格子で済まないか確かめる

`GrowingFigures.multigrid(N)` は方向の数 N を変えるだけで別の図形になる（N=4 で8回対称、7 で7回対称、6 で12回対称…）。
新しい対称の数が欲しいだけなら、`GENERATORS` に1行足して 3 へ進む。

```js
nonagon: { name: '九角（9回対称）', make: multigrid(9) },
```

## 1. 候補を選ぶ（SPEC.md「採否の基準」を先に読む）

- 閉じた多角形で平面を隙間なく覆えるか（円の中に収まる図形は不可）
- タイルを2つに分ける自然な分け方があるか（形の種類・鏡像・並びの腕など）。色1と色2の層になる
- 周期が無い、または場所で見え方が変わるか
- `SPEC.md` の「見送った図形」に同じ理由で落ちたものが無いか

## 2. 生成器を書く

`generators.js` に関数を足し、`GENERATORS` に登録する。守ること：

- 返すのは `[{ p, cls, dir }]` だけ。DOM や canvas に触れない（Node で検査するため）
- 画面（`W`×`H`）＋余白に掛からない部分は、**分割の途中で捨てる**（全部作ってから捨てると重い）
- 2枚を組にして1枚を作る図形（ペンローズの菱形など）は、余白を `margin`（タイル2枚分）とり、画面の縁で片割れだけが残らないようにする
- タイルの大きさは `edge` に合わせる（Chromebook で約25px。これで枚数が基準に収まる）
- 育ち始める点 `(ox, oy)` を図形の中心にする（花形・螺旋の中心がそこに来る）
- `dir`（0..4）は向きなど、見た目の段に効く量から決める

## 3. 機械で検査する

```
node growing-figures/check.cjs <id>
```

隙間・重なり・枚数・色の片寄り・生成時間を、Chromebook とスマホの画面で測る。✗ が出たら直す。
（実例：ひまわりは中心の2つの細胞を捨てていて、スマホの画面で隙間 0.2% が出た。0 番の点を足して直した）

## 4. 目で見る

`sampler.html` をブラウザで開く（同じフォルダの `generators.js` を読む。ローカルなら
`python3 -m http.server` をこのフォルダで起動して開く）。

- 図形を選び、「0にもどす」から「50回」を数回押して、①→②→③の育ち方を見る
- 基準5（全体を掴ませない）・基準6（色の層で別の構造が浮かぶ）を確かめる
- 色2を切り替えて、学年の色と並べたときに濁らないか見る

## 5. 記録する

- `SPEC.md` の「登録済みの図形」に1行足す（採らなかったら「見送った図形」に理由と一緒に足す）
- 各サイトに入れるときは、サイトの共通エンジンに生成器を写し、写し元（このリポジトリのコミット）をコメントに書く
