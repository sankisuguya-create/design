# 算数ロボ（マスコット）

算数タイムアタックのマスコット。いまは**頭だけ**を正本として登録している（胴体は未決）。

![8コマ](loading_frames.png)

## 顔

| 部位 | 形 | 色 |
|---|---|---|
| 頭 | 横長の楕円（32×34ドットの枠）。左上に光沢、右下に影 | 白 `#E6ECF4`・光 `#FFFFFF`・影 `#B4C2D6`、輪郭 `#1B2238` |
| 目 | 縦長の角丸、横線2本（画面の走査線）。右目が1ドット高い | そら `#49B9DF`、線 `#D9F3FC` |
| 口 | 四角の格子（スピーカーの網） | 口の中 `#2B3450`、格子 `#9FB0C8` |
| アンテナ | 曲がった茎＋右上を向いたしずく形の葉 | 葉 ミント `#35D0A5`・影 `#1F9C7A` |

元は利用者の手描き。色は算数TAの学年の色（2年そら・3年ミント）と背景の紺から取った。

## 読み込み中アニメーション（now loading）

8コマ×110ms（約0.9秒で1周）。

1. 1・2ドット浮いて着地し、着地のコマで頭が横に広がる（つぶれ）
2. 茎の上半分と葉が遅れて左右に揺れる（根元は頭に付いたまま）
3. 目の横線が上から下へ流れる
4. 下の「now loading」の点が1つずつ増える（SVG のときだけ）

| ファイル | 用途 |
|---|---|
| `loading.py` | 生成器（正本）。直すときはここを直して書き出し直す |
| `loading.svg` | 動くもの（SMIL）。そのまま `<img>` や埋め込みで使える |
| `loading_sheet.svg` | 等倍の8コマを横に並べたスプライト（1コマ32×34）。CSS の `steps(8)` で送る |
| `loading_frames.png` | 8コマを拡大して並べた確認用 |
| `face.png` | 止めた顔（最初の版） |
